# Vježba 4

## Zadatak 4

Napisati program za zbrajanje i množenje polinoma. Koeficijenti i eksponenti se
čitaju iz datoteke.

Napomena: eksponenti u datoteci nisu nužno sortirani.

## Datoteke

| Datoteka | Opis |
|----------|------|
| `zadatak4.c` | rješenje zadatka (polinom = sortirana vezana lista članova) |
| `polinomi.txt` | ulazna datoteka: svaki redak je jedan polinom, parovi `koeficijent potencija` |

Primjer `polinomi.txt`:

```
3 2 5 0 2 4
1 1 -3 2 -2 0
```

prvi redak je 3x² + 5 + 2x⁴, drugi je x − 3x² − 2.
