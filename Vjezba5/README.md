# Vježba 5

## Zadatak 5

Napisati program koji iz datoteke čita postfiks izraz i zatim korištenjem stoga računa
rezultat. Stog je potrebno realizirati preko vezane liste.

## Datoteke

| Datoteka | Opis |
|----------|------|
| `zadatak5.c` | rješenje zadatka (stog kao vezana lista, Push/Pop) |
| `izraz.txt` | ulazna datoteka: postfiks izraz, brojevi i operatori odvojeni razmakom |

Primjer `izraz.txt`:

```
5 1 2 + 4 * + 3 -
```

što je infiksno 5 + (1 + 2) · 4 − 3 = 14.
